# FirePath Web

Static GitHub Pages site for FirePath.

## Pages URL

After pushing this folder to GitHub, enable GitHub Pages from the repository settings.

Typical privacy policy URL:

```text
https://<github-username>.github.io/<repository-name>/privacy.html
```

## Local Preview

Because this is a static site, you can open `index.html` directly in a browser.

For a local server:

```bash
ruby -run -e httpd . -p 4173
```
